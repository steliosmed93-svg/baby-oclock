# Μαζί στην Εξωσωματική

Εφαρμογή (PWA) για ασθενείς σε κύκλο εξωσωματικής γονιμοποίησης: κύκλος και βήματα, φάρμακα με υπενθυμίσεις, ημερολόγιο συμπτωμάτων με σημεία κινδύνου, υπερηχογραφήματα, γνώση, ψυχολογική στήριξη, ερωτήσεις για τον γιατρό και στοιχεία κλινικής.

Όλα τα δεδομένα αποθηκεύονται τοπικά στη συσκευή (localStorage). Η εφαρμογή δεν αντικαθιστά τις οδηγίες του γιατρού.

Συνοδευτική εφαρμογή για γιατρούς: [ivf-protocols](https://github.com/steliosmed93-svg/ivf-protocols)
