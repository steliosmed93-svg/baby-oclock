# Baby O’Clock

Εφαρμογή (PWA) για ασθενείς και ζευγάρια σε κύκλο εξωσωματικής γονιμοποίησης: κύκλος και βήματα, φάρμακα με υπενθυμίσεις, ημερολόγιο συμπτωμάτων με σημεία κινδύνου, υπερηχογραφήματα, γνώση, Fertility Psy Coach (ασκήσεις για τη γυναίκα και το ζευγάρι, check-in ζευγαριού, οδηγός συναισθημάτων, σε συνεργασία με την ψυχολόγο Βαρβάρα Παπασιδέρη: TikTok @ask.varvara.psy, Instagram @varvara_papasideri), ερωτήσεις για τον γιατρό και στοιχεία κλινικής.

Όλα τα δεδομένα αποθηκεύονται τοπικά στη συσκευή (localStorage). Η εφαρμογή δεν αντικαθιστά τις οδηγίες του γιατρού.

Συνοδευτική εφαρμογή για γιατρούς: [ivf-protocols](https://github.com/steliosmed93-svg/ivf-protocols)
